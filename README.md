
# Face Recognition Attendance System

## Project Description
An automated attendance management system using
Python, OpenCV and Face Recognition technology.

The system identifies registered students through
a webcam and automatically records their attendance.

## Features
- Student face registration
- Real-time face detection
- Face recognition using LBPH
- Automatic attendance marking
- Duplicate attendance prevention
- CSV attendance reports

## Technologies Used
- Python
- OpenCV
- NumPy
- LBPH Face Recognition
- CSV

## Installation

Install the required libraries:

pip install opencv-contrib-python numpy

## How to Run

1. Register students:
   python register.py

2. Train the recognition model:
   python train.py

3. Start attendance:
   python attendance_system.py
